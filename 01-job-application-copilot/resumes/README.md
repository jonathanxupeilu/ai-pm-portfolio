# resumes —— 简历母版与派生件

## 为什么不放真实简历

真实投递稿含姓名、手机号、邮箱与完整任职信息，不适合随公开仓库分发。
本目录只保留**虚构示例**，用于演示本技能的母版结构与派生机制。

## 母版 → 派生件的工作方式

```
baseline.md（母版：事实全量、口径统一）
      │
      ├─ 读取 JD → 抽取关键词与硬门槛
      ├─ 选择企业类型模板（大厂 / 互联网 / 传统银证保 / 小型创业 / 通用）
      ├─ 按 JD 调整：摘要叙事、项目顺序、技能区措辞
      └─ 派生输出：一岗一版 .md + .html（两份必须同源）
                              │
                              └─ 过 ATS 自检（查占位符与死词）→ 🟢 才可投
```

**硬性约束**：派生件不得引入母版与事实库之外的新事实。所有量化指标必须能在事实库中找到出处。
